# PinoyBuyNSell logo

The brand mark combines a shopping bag, a letter P, a gold sun and an upward exchange arrow. Colors match the marketplace's blue, red, green and gold palette. The website pairs the mark with an accessible HTML wordmark for crisp, readable lettering.

- `pinoybuynsell-mark.png`: transparent logo for the website header, footer and browser icon.
- `pinoybuynsell-facebook-profile.png`: square logo on a white background with room for Facebook's circular profile crop. Upload this file as the Facebook Page profile picture.

The website uses Next Image to serve small optimized header/footer versions rather than sending the full-resolution logo to every visitor. Root page sharing metadata uses the square logo; product pages continue to use each item's own photo and details.

To update the Facebook Page, download the profile PNG, switch into the PinoyBuyNSell Page on Facebook, click its profile picture, choose the option to update/upload a photo, and save. This code change does not automatically change the Facebook Page's profile picture.
